# Troubleshooting API 401 Errors
## Symptoms
API requests return HTTP 401.

## Common causes
A 401 response usually means the request is missing a valid authentication credential. Common causes include a missing Authorization header, an expired token, or an invalid token.

## Resolution
Confirm that the request contains a valid Bearer token and that the token belongs to the intended workspace.
