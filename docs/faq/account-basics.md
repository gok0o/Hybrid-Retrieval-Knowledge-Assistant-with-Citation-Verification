# Account Basics
## What is FlowDesk?
FlowDesk is a customer-support workflow platform used to manage tickets, teams, automations, and customer conversations.

## Can one account have multiple workspaces?
Yes. An organization can create multiple workspaces and assign users to the workspaces they need.
