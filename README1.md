# Support Knowledge Copilot with Verified Citations

Phase 1 starter corpus for a production-oriented RAG project.

## Domain
FlowDesk — a fictional SaaS support/workflow platform.

## Corpus
48 Markdown documents across:
- FAQ
- Troubleshooting
- Onboarding
- API documentation
- Release notes
- Policies

Documents intentionally overlap so retrieval is not trivial.

## Phase 1 contracts
- `config/metadata_schema.json`
- `config/assistant_contract.json`
- `evaluation/golden_questions.json`

## Important
This corpus is synthetic and intended for engineering/evaluation practice.
Do not present it as real company documentation.
