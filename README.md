# Production-Ready RAG Architecture for SaaS Support

![RAG System Architecture](https://img.shields.io/badge/Architecture-RAG-blue?style=for-the-badge) ![Python](https://img.shields.io/badge/Python-3.10%2B-blue?style=for-the-badge) ![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=for-the-badge&logo=fastapi) ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit) ![Qdrant](https://img.shields.io/badge/Qdrant-f90b43?style=for-the-badge&logo=qdrant)

An end-to-end, production-grade Retrieval-Augmented Generation (RAG) system built to serve as an intelligent support copilot. This project demonstrates advanced retrieval techniques, rigorous evaluation, and verifiable LLM outputs for a fictional SaaS platform ("FlowDesk").

## 🌟 Key Features

### 1. Robust Data Pipeline (`scripts/ingest.py`)
- **Smart Chunking**: Supports both heading-aware recursive chunking (to preserve semantic boundaries) and fixed-size overlapping windows.
- **Metadata Propagation**: Automatically extracts and propagates YAML frontmatter to chunk payloads for precise filtering.

### 2. Advanced Retrieval Strategies (`scripts/index.py` & `scripts/retrieve.py`)
- **Hybrid Search**: Combines Dense Vector Retrieval (Qdrant) and Sparse Lexical Retrieval (BM25) to capture both semantic meaning and exact keyword matches.
- **Reciprocal Rank Fusion (RRF)**: Merges dense and sparse search results effectively without needing score normalization.
- **Cross-Encoder Reranking**: Re-scores the top fused results using a cross-encoder model to maximize relevance.

### 3. Verifiable Generation (`src/generation/`)
- **Citation Grounding**: Every factual claim generated by the LLM is explicitly cited with the exact document chunk it was sourced from.
- **Confidence Scoring**: Outputs a confidence metric based on retrieval quality and citation support rates.
- **Anti-Hallucination Guardrails**: Strictly refuses to answer questions outside the scope of the provided context.

### 4. Rigorous Evaluation (`scripts/eval.py`)
Evaluates the RAG pipeline against a curated "golden dataset", measuring:
- **Retrieval Metrics**: Hit@1, Hit@5, Recall@5, MRR.
- **Answer Quality**: Reference Answer Similarity, Citation Support Rate.
- **Refusal Correctness**: Ability to identify and accurately refuse unanswerable questions.

### 5. Deployment-Ready Interfaces
- **FastAPI Backend**: Exposes the complete RAG pipeline as a scalable, async REST API (`app.py`).
- **Streamlit Dashboard**: A user-friendly interactive UI for testing and exploring the assistant's capabilities (`dashboard.py`).

## 🚀 Getting Started

### 1. Environment Setup
Install dependencies and set your API keys.

```bash
pip install -r requirements.txt
```

Create a `.env` file at the root:
```env
OPENROUTER_API_KEY="your-api-key-here"
OPENROUTER_MODEL="openai/gpt-4o-mini"
```

### 2. Start the Vector Database
Launch Qdrant using Docker Compose:
```bash
docker-compose up -d
```

### 3. Build the Knowledge Base
Run ingestion (chunking) and indexing:
```bash
# Ingest markdown files into chunks
python scripts/ingest.py --source docs --strategy heading --rebuild

# Build Qdrant (dense) and BM25 (sparse) indices
python scripts/index.py
```

### 4. Evaluate the Pipeline
Measure the performance of your system against the golden dataset:
```bash
python scripts/eval.py --strategy hybrid
```
Results will be generated as a detailed Markdown report in `reports/evaluation_report.md`.

### 5. Run the Application
Start the FastAPI backend:
```bash
uvicorn app:app --reload
```

Start the Streamlit dashboard:
```bash
streamlit run dashboard.py
```
